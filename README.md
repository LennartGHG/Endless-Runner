# spiel-versuch
This is a endless runner game I programmed

CONTROLS: 
jump: W/arrow up/space bar
crouch: S/arrow down
reset(in the game over scene): W/arrow up/space bar

To run it on your computer, you have to follow these steps:
1. Download Godot
2. Download the code as a zip File
3. extract the zip File
4. Copy the file path
5. Go into Godot
6. Click on Import in the top left of your screen
7. past your file path in the top
8. click on "chose this file"
9. click on "import" and activate "Edit Now"
10. click on the play button on the top right of your screen to play
11. (click on the tree dots in the top right and choose "keep Aspect Ratio"

When you want to play the game again later you just have to open godot and doubleclick the project and hit the play button.
